# Chainbills - CosmWasm

Chainbills is a cross-chain payment gateway that allows anyone (hosts) to receive any amount of cryptocurrency from everybody (payers), powered by CCTP and Wormhole. Chainbills deducts 2% from all withdrawals for fees and maintenance.

This CosmWasm Contract code was generated with [Sylvia](https://github.com/CosmWasm/sylvia-template).
